# 私有 GitHub Actions 单次无签名验收

`tvos-super-app/` 来自用户收到的 0.1.0 ZIP，未修改产品代码。额外的工作流在外层。唯一的触发器是 `workflow_dispatch`，工作流须在仓库默认分支存在。输入该快照完整 40 位提交 SHA，以便工作流同时核查实际 HEAD、事件提交、所有源文件哈希。只运行一次，不发布或保留 Actions artifacts。只有确认账户剩余额度与无外付费用保证后才可触发；15 分钟不是费用开关。不要从公共仓库执行。

工作流使用标准 `macos-26` ARM64 执行器，固定已列明具有 tvOS 26.5 Simulator 的 Xcode 26.5。若实际镜像不同，预检失败，不自动下载额外的 SDK，也不自动重试。一次 job 核查 Foundation 数据逻辑、无签名 tvOS 编译以及模拟器安装、启动与进程存活。启动不是播放器操作证明。日志记载准确提交与 SDK，无外部播放请求。

下一阶段如需另测播放，应在单独明确标记的变体指定本地自主生成测试片段，不替换或篡改这个 0.1.0 快照，也不将样片标成真实红果。tvOS 模拟器与 Apple TV 真机是不同验收环境。
