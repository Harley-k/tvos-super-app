# SuperTV｜Apple TV 与 Mac 私家放映厅

**当前候选版：** [从这里开始使用 0.3.0](app/README.md) · [双平台验证与下载](https://github.com/Harley-k/tvos-super-app/actions/workflows/supertv-rc.yml)。

- 原生选择影片、播放、分集续播和直播/短剧清单导入，包含开放影片《WING IT!》和两段原创测试片。
- Mac 构建面向 Apple 芯片；Apple TV 真机需要用户自己的 Xcode 签名。模拟器包不能直接安装到电视。
- B 站、红果、抖音和大陆电视台不是四个已经接入的节目库；逐个平台的实际能力见[说明](app/README.md#平台边界)。
- [保留的 0.2.0 源码快照](releases/v0.2.0/)；[最初 tvOS 版本](tvos-super-app/)。
